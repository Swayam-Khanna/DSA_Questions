👀 Number of Visible People in a Queue🧩 Problem StatementThere are $n$ people standing in a queue, numbered from $0$ to $n - 1$ from left to right. You are given an array heights of distinct integers, where heights[i] represents the height of the $i^{th}$ person.  👁️ Visibility RuleA person $i$ can see person $j$ to their right if:$i < j$, and  All people between them are shorter than both of them.  Formally:$$\min(\text{heights}[i], \text{heights}[j]) > \max(\text{heights}[i+1] \dots \text{heights}[j-1])$$📊 Visual ExplanationExample WalkthroughInput: heights = [10, 6, 8, 5, 11, 9]  Output: [3, 1, 2, 1, 1, 0]  Person 0 (Ht: 10): Sees heights 6, 8, and 11. The person with height 11 blocks the view of anyone further right.  Person 1 (Ht: 6): Sees only height 8.  Person 2 (Ht: 8): Sees heights 5 and 11.  Person 3 (Ht: 5): Sees height 11.  Person 4 (Ht: 11): Sees height 9.  Person 5 (Ht: 9): Sees 0 people (last in line).  ⚙️ Constraints$1 \le n \le 10^5$  $1 \le \text{heights}[i] \le 10^5$  All heights are unique  🧠 Intuition & ComplexityMonotonic Stack: The problem is solved efficiently by processing the array from right to left using a stack to maintain potential visible candidates.  Efficiency: Each person is pushed and popped exactly once, ensuring a time complexity of $O(n)$.  Space Complexity: $O(n)$ for the stack storage.  🚀 ImplementationThe complete Java solution using a Monotonic Stack can be found in the accompanying file in this repository.📌 TagsMonotonic Stack | Arrays | Stack | Greedy  ✍️ AuthorSwayam Khanna  Third-year B.Tech in Computer Science and Engineering  Chitkara University
